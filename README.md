# Statistical Learning Samples

Timed, self-contained practice tasks for applied statistics / ML interview prep — each one a small, worked dataset with a task prompt, meant to be attempted under a time limit without AI assistance, then reviewed afterward.

## Setup

Requires Python 3.11+ and `curl`.

1. Create and activate a virtual environment:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```
2. Install [Poetry](https://python-poetry.org/) into that virtual environment:
   ```bash
   pip install poetry
   ```
3. Tell Poetry to install directly into the already-active virtual environment, rather than creating its own nested one:
   ```bash
   poetry config virtualenvs.create false --local
   ```
4. Install dependencies:
   ```bash
   poetry install
   ```

After setup, launch Jupyter from the activated venv (`jupyter lab` or `jupyter notebook`) to work through a task's `task.ipynb`.

## Tasks

Each task lives in its own directory under `tasks/`, with a `TASK.md` describing the scenario and what to do, a dataset, and (after attempting it) a worked `task.ipynb`.

- **`tasks/device_traffic_classification/`** — classify IoT device type from aggregated home-network traffic features (synthetic data, generated by `generate_data.py`). Multiclass, moderately imbalanced classes, missing values and injected outliers to find.
- **`tasks/credit_card_fraud/`** — predict whether a credit card transaction is fraudulent from transaction/cardholder features (synthetic data downloaded from Kaggle). Binary, extreme class imbalance (~1.5% positive), includes a real categorical feature.

## Working a task

1. Open the task's `TASK.md` and read the scenario and data dictionary.
2. If the task has a `generate_data.py`, run it once to produce the CSV — don't re-read the generator afterward, it'll spoil the exploratory analysis.
3. Set a timer if you want the timed version (most tasks are sized for ~60 minutes), and work through it without AI assistance.
4. Review the result afterward against the task's own worked `task.ipynb`, if present.
